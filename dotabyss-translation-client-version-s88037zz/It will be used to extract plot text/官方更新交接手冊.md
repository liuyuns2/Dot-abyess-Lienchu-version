## 3. 官方更新當天：一鍵執行

開啟 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
Set-Location "E:\離線板\files"
.\OfficialNovelUpdate.ps1
```

若補抓指定日期：

```powershell
.\OfficialNovelUpdate.ps1 -UpdateDate "2026-08-06"
```

若路徑不同：

```powershell
.\OfficialNovelUpdate.ps1 `
  -UpdateDate "2026-08-06" `
  -BaseDir "E:\離線板" `
  -RepoRoot "D:\dotabyss-translation\GITHUB-dotabyss-translation" `
  -PythonExe "E:\離線板\files\.venv\Scripts\python.exe"
```

腳本會依序完成：

1. 從官方 R18 端點取得版本資訊。
2. 下載 MasterData 與 `catalog_1.bin`。
3. 解析 catalog 為 `assets.json`。
4. 只建立小說文本 bundle manifest。
5. 只下載小說文本，不下載全部遊戲資源。
6. 解出最新官方日文 key、`zh_Hant.json`、官方原始 TXT。
7. 從三個既有 novels 來源依日文 key 套用翻譯記憶。
8. 找出仍為空字串的 value。
9. 產生待處理資料夾與「純全新資料夾」清單。
10. 比較上一個 `official_update_*` 的 L2D ID。

### 為什麼不能只比對資料夾名稱

官方可能修改既有腳本中的一句原文，例如：

- 刪掉或增加一小段文字。
- 同一句裡少一個詞。
- 把漢字寫法換成假名。

資料夾名稱不變時，單純比對資料夾會漏掉。新版流程會先建立「官方最新 key + repo 既有翻譯」，凡是 repo 沒有完全相同 key 的句子都保持 `""`，因此舊腳本改字也會出現在 `pending_novels`。

## 5. 翻譯工作

只編輯：

`pending_novels\<script_id>\zh_Hant.json`

JSON 格式：

```json
{
  "日文原文 key": "繁體中文翻譯 value",
  "新出現的日文": ""
}
```

規則：

1. **只改 value，不改日文 key。**
2. 不新增 `zh_Hans.json`。
3. 保留 `<br>`、`<user>`、顏文字、`♪`、`♡` 及其他控制標籤。
4. 譯名以 `-X-\names\zh_Hant.json` 為最高優先。
5. 使用臺灣繁體中文，避免「咱們、這兒、視頻、軟件、默認」等用語。
6. 成人文本只忠實翻譯，不任意增加、刪減或改寫情節。
7. 不使用 OpenAI API 自動補翻；目前流程是人工／Codex 協作翻譯。

新增譯名時，同步更新：

`D:\dotabyss-translation\GITHUB-dotabyss-translation\-X-\names\zh_Hant.json`

必要時再同步客戶端版本的 names。

## 7. 同步回 repo

先查看 Git 狀態並備份：

```powershell
Set-Location "D:\dotabyss-translation\GITHUB-dotabyss-translation"
git status --short
```

將 `pending_novels` 中每個 `zh_Hant.json` 複製到主要 repo：

```powershell
$date = "2026-08-06"
$pending = "E:\離線板\output\official_update_$date\pending_novels"
$repo = "D:\dotabyss-translation\GITHUB-dotabyss-translation\-X-\novels"

Get-ChildItem -LiteralPath $pending -Directory | ForEach-Object {
    $source = Join-Path $_.FullName "zh_Hant.json"
    $targetDir = Join-Path $repo $_.Name
    if (Test-Path -LiteralPath $source) {
        New-Item -ItemType Directory -Path $targetDir -Force | Out-Null
        Copy-Item -LiteralPath $source -Destination (Join-Path $targetDir "zh_Hant.json") -Force
    }
}
```

再次檢查差異：

```powershell
git status --short
git diff --stat
```

確認只包含預期的 `novels/*/zh_Hant.json` 與 `names/zh_Hant.json` 後再提交：

```powershell
git add -- "-X-/novels" "-X-/names/zh_Hant.json"
git commit -m "更新 2026-08-06 官方劇情翻譯"
git push
```

不要把 `assets.json`、catalog、bundle、整個 `output` 提交進翻譯 repo。

## 8. 保留指定文本

若官方把預載內容撤下，應把重要文本另存於當次版本資料夾。建議結構：

```text
preserved_novel_texts/
├─ novels/        # zh_Hant.json
└─ official_raw/  # 官方完整 TXT
```

角色場景 ID 通常為：

- `hmr_角色ID00011`：開場／銜接
- `hmr_角色ID00012`：主要 L2D 場景
- `hmr_角色ID00013`：收尾
- 第二、三組則為 `21～23`、`31～33`

若只保存 `12／22／32`，得到的是三段主要 L2D 文本；若要完整劇情，應連同 `11～13／21～23／31～33` 一起保存。

## 9. 常見錯誤

### `ModuleNotFoundError: requests / UnityPy / msgpack / Crypto / rich`

重新執行：

```powershell
& "E:\離線板\files\.venv\Scripts\python.exe" -m pip install `
  requests msgpack pycryptodome rich UnityPy
```

### `OPENAI_API_KEY is not set` 或 API 429

目前正式工作流不使用 API。不要再執行 `AutoTranslate.py` 或舊版 API 自動翻譯階段。

### `download_failed.txt` 有內容

用完全相同的 `DownloadCatalogBundles.py` 指令重跑。已完成且大小正確的檔案會自動跳過，只補失敗項目。

### `MasterData.json` 找不到

確認執行的是 `FetchLatestCatalogOnly.py --output <當次日期資料夾>`，並查看 `latest_catalog_info.json`。

### `pending_novels` 是 0 個

可能表示：

1. 官方只有資源更新，沒有新文本。
2. 新文本已存在於三個比對來源之一。
3. 所有官方 key 都能從翻譯記憶完整套用。

仍需查看 `l2d_changes.txt` 與 `new_folders_only\index.md`。

### catalog 裡的劇本突然消失

不要連動刪除 repo。官方可能只是撤下預載資料。保留上一版 `official_update_*`，先記錄「上一版有、本版無」，等下一次更新再判斷。

## 10. 每次交付前檢查表

- [ ] 使用新日期資料夾，沒有覆蓋上一版。
- [ ] 記錄 AssetVersion、MasterDataVersion、catalog hash。
- [ ] 下載失敗 0、解包失敗 0。
- [ ] 檢查 `pending_novels` 與 `new_folders_only`。
- [ ] 檢查既有資料夾內的新 key，不能只看資料夾名稱。
- [ ] 只翻 `zh_Hant.json` value。
- [ ] 譯名符合 `names\zh_Hant.json`。
- [ ] 空值、JSON parse error、tag error 都為 0。
- [ ] Git diff 只含預期小說與譯名檔。
- [ ] 不提交大型 catalog、bundle、下載目錄。
- [ ] 重要預載文本另存，避免下版撤下。
- [ ] Unity 離線版更新另做備份、Build 與實機播放驗證。
